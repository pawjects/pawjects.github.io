## 🐾 About

Pawjects is an independent open-source collective focused on building useful software across Android, Web and Telegram.

We create projects that are:

- ⚡ Lightweight
- 🎨 Modern
- 🔓 Open Source
- 🧩 User Focused

Instead of collecting ideas, we build them.
